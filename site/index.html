loi

A small C-like language that compiles source to LLVM IR. Expressive macros and region-based memory, function types, effects, and a metaprogramming preprocessor — all in one tool.

Read the docs Browse examples

Features

C-like syntax

Functions by assignment, hybrid variable declarations, semicolons, structs/unions, pointers, arrays, inline asm.

Typed function pointers

First-class (a: int, b: int) -> int !IO types: alias with `type`, null initializers, effect tracking through calls.

Effects

Functions declare `!IO,Alloc`. Call sites are checked against the caller's effect set.

Regions

Lexical regions with bump allocators and `loi_region_alloc`.

Macros & meta

Object/function-like @(define ...), conditionals, @repeat/@for, @stringify, @paste, and variadic macros.

Preprocessing & packages

@inc (loi files/packages), @cinc (C headers), branch-scoped defines, compile-time codegen.

LLVM IR output

Emits optimizable IR and compiles to native via clang. Target triple included.

Reflection

`@sizeof`, `@offsetof`, `@typeof`, struct layout control with `@align`/`@pack`.

Quick start


import std

main = () -> int
{
    loi_print_str("hello from loi\n");
    return 0;
}

$ ./loi examples/01_basics.loi --run
120   # exit code reflects program result

Build Project: make in the source tree. Invoke ./loi file.loi --run to compile, run, and print the exit code.

What makes loi different

  • Heavy @ sigil for compile-time metaprogramming instead of a separate tool.
  • Effect annotations that actually restrict which functions may be called.
  • Region-scoped manual memory with lexical lifetime.
  • Typed callbacks and function pointers that don't lose their effect contract.
