Documentation

A small C-flavored language that compiles to LLVM IR, with a rich @ metaprogramming layer, effects, regions and typed function pointers. The authoritative grammar lives in docs/syntax.md in the repository.

Introduction

loi combines C-like syntax (functions assigned to names, hybrid variable declarations, semicolons, structs/unions, pointers, arrays, inline asm) with compile-time metaprogramming via the @ sigil, effect annotations (!IO,Alloc), lexical regions, and typed function pointers. The output is LLVM IR, compiled to native via clang.

Every file declares @package(name) and reaches the runtime through the std package: @inc std followed by calls such as std.print_int(42). The internal loi_ symbol prefix is never written in source.

Getting started


@package(demo)

@inc std

factorial = (n: int): int
{
    if (n <= 1) { return 1; }
    return n * factorial(n - 1);
}

main =
{
    int x = 5;
    if (x < 10) { return factorial(x); }
    else { return 0; }
}

Types


Type        := BaseType TypeSuffix*
BaseType    := Primitive | Ident | 'fn' '(' TypeList? ')' '->' Type ('!' EffectList)?
             | '(' Type ')'
             | '(' ParamName ':' Type (',' ParamName ':' Type)* ')' '->' Type ('!' EffectList)?
             | '@' 'typeof' '(' Expr ')'
             | 'type' Ident '=' Type

TypeSuffix  := '*' | '[' Expr? ']'
EffectList  := Ident (',' Ident)*

Primitives include int float double char bool byte short long void unsigned.... Pointers use *. Arrays are postfix and only postfix: int[10] a; / int[] a; (the old [10]int form is not parsed). Aliases: type CmpFn = (a: int, b: int) -> int;.

Control flow

if/else, while, do-while, for (declarations allowed in init), switch/case/default, break, continue. region r(size) { ... } opens a lexical bump scope.

Memory & regions


void* p = std.alloc(8);
*p = 42;
int v = *p;

region r(64) {
    void* q = std.region_alloc(r, 8);
    *q = 5;
}

Functions & effects


worker = (arg: void*): void* !IO,Alloc
{
    std.print_str("region block");
    return arg;
}

main = () -> int !IO,Alloc
{
    region r(64) { void* v = worker(r); }
    return 0;
}

Effects after ! name capabilities (IO, Alloc, ...). A caller may only call functions whose effects are a subset of its own; assigning through a function pointer may not widen effects.

Lexical capabilities & dual effects


@package(mem)

@capability(Read, Write)

peek = (buf: ptr, c: @cap(borrow Read)): int { return *buf; }
poke = (buf: ptr, c: @cap(Write)): void { *buf = 42; }

/* producer: return type authorises @grant */
new_page = (buf: ptr): @cap(Write) {
    @grant(Write) w;
    return w;
}

/* dual effects: @needs + !IO bridge */
@capability(Filesystem)
load_cfg = (): int !IO @needs(Filesystem) { return 42; }

main = (): int !IO {
    int p = 0;
    @cap(Write) w = new_page(&p);
    poke(&p, w);                      /* consumes w */
    @grant(Filesystem) fs;
    int cfg = load_cfg();
    @drop(fs);
    region r(64) with Write { }                 /* ambient cap released with the region */
    @grant(Read) rd;
    @with_cap(Read) { peek(&p, Read); }         /* ambient borrow, block-scoped */
    @drop(rd);
    return p;
}

@cap(Write) is a linear, zero-cost permission token. @grant births one at a root (main, @root, a producer/declared @gives). @refine weakens it, @drop discards it. @cap(borrow Read) doesn't consume. A live capability discharges !X (effects bridge). @needs(X) states what a function requires (dual of !Effects). Regions may carry with Cap as w and blocks may open @with_cap(Cap) { ... } — both make a live proof ambient, released at end. A trailing @cap argument may be omitted when exactly one live proof discharges it (poke(&x) for poke(&x, w)). See docs/capabilities.md and docs/needs.md.

Typed function pointers


type CmpFn = (a: int, b: int) -> int;

my_less = (a: int, b: int): int { return a < b; }
cmp: CmpFn = null;              // variable holding a function pointer

main = () -> int
{
    cmp = my_less;               // assign a function as a value
    std.print_int(cmp(2, 3));      // 1
    apply = (f: (a:int,b:int)->int, x:int, y:int): int { return f(x, y); }
    std.print_int(apply(my_less, 2, 3));
    return 0;
}

Metaprogramming / preprocessor

Everything @ runs during a pre-lexing pass. Order of directives is preserved; branches skipped by @if never register their @define.

  • @(define NAME replacement) / @define NAME replacement
  • @(inc ...) / @(cinc ...) (see Include)
  • @if(COND) { ... } @elif(...) { ... } @else { ... }
  • @repeat(n) { body } / @for(i, A, B) { body }
  • @sizeof(T), @offsetof(T, field), @typeof(expr)
  • @section("name") { ... }, @align(n), @pack
  • @attr(local, inline, link_name("sym")) — extensible metadata on the next declaration

Macros: stringify, paste, variadic


@inc std
@(define STR(x) @stringify(x))
@(define CONCAT(a, b) @paste(a, b))
@(define LOG(level, ...msg) { @if(level >= 1) { std.print_str(msg); } })

int foobar = 77;

main = () -> int !IO
{
    std.print_str(STR(hello));        // "hello"
    std.print_str(STR(LIMIT));         // "LIMIT" (raw, not expanded)
    int foo = 1, bar = 2;
    std.print_int(CONCAT(foo, bar));  // foobar -> 77
    LOG(1, "log: variadic works\n");
    return 0;
}

@stringify captures raw token text; @paste concatenates fragments into a token; ...msg joins the remaining args with ", ". @if inside macros is resolved in a second pass after expansion.

Packages, namespaces & attributes

Every loi file declares a package with @package(name). The entry file and every @inc-ed file are checked; a missing declaration is an error, and the old bare package name form is rejected. Dotted names are allowed (@package(core.utils)).

Files that declare the same @package form a single namespace: a symbol defined in one is visible to the others without qualification. Includes splice textually, so the compiler re-asserts the enclosing package after each included file and symbols never leak across packages.

Symbols are global by default. Mark one @attr(local) to keep it private to its package — referencing it from another package is a type error ('helper' is local to package 'core' and is not visible here).

@package(core)

@attr(local)
helper = (): int { return 7; }   // only visible inside `core`

@attr(global, inline, link_name("core_api"))
public_api = (): int { return helper(); }

@attr(...) attaches extensible metadata to the next declaration: visibility (local/global), link_name("sym"), section("name"), inline, no_return, pure, must_use, extern. Unknown attributes are recorded in the AST and otherwise ignored. @attr(must_use) emits an advisory warning (not an error) when a call's result is discarded; void functions never warn.

Use @inc pkg or @inc pkg.sub to load package sources. Dots are mapped to directory separators and resolution follows the same search paths (./lib, ./packages, standard system paths, LOI_PATH). There is no import keyword.

The standard package is std: after @inc std, call runtime helpers as std.print_int, std.alloc, std.region_alloc, and so on. The code generator rewrites std.NAME to the matching runtime symbol. See lib/ for the std package layout.

  • Resolution: file's directory, ./lib, ./packages, /usr/share/loi, /usr/local/share/loi, LOI_PATH. All inclusions use @inc / @cinc.
  • @cinc searches ., /usr/include, /usr/local/include, /usr/include/x86_64-linux-gnu.
  • Includes are guarded automatically (a file is inlined at most once per build), so libraries need no manual guards and cycles are safe. C ABIs are declared with extern ...;.

Build & run


make
./loi examples/01_basics.loi --run          # compile + run
./loi file.loi --emit=ir --out=file.ll      # emit LLVM IR
./loi file.loi --emit=asm --out=file.s      # emit assembly

Limitations

  • No C-standard-header ABI modeling; @cinc is a verifier, not importer.
  • C-style variadic functions are deferred — use variadic macros.
  • Built-in runtime calls carry no effect annotations.
