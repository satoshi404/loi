Documentation

A small C-flavored language that compiles to LLVM IR, with a rich @ metaprogramming layer, effects, regions and typed function pointers. The authoritative grammar lives in docs/syntax.md in the repository.

Introduction

loi combines C-like syntax (functions assigned to names, hybrid variable declarations, semicolons, structs/unions, pointers, arrays, inline asm) with compile-time metaprogramming via the @ sigil, effect annotations (!IO,Alloc), lexical regions, and typed function pointers. The output is LLVM IR, compiled to native via clang.

Files usually begin with import std, which brings the runtime helpers (printing, math, threads, regions, ...) into scope at the compiler level. (Runtime helpers are also linked automatically even without import std.)

Getting started


import std

factorial = (n: int): int
{
    if (n <= 1) { return 1; }
    return n * factorial(n - 1);
}

main =
{
    int x = 5;
    if (x < 10) { return factorial(x); }
    else { return 0; }
}

Types


Type        := BaseType TypeSuffix*
BaseType    := Primitive | Ident | 'fn' '(' TypeList? ')' '->' Type ('!' EffectList)?
             | '(' Type ')'
             | '(' ParamName ':' Type (',' ParamName ':' Type)* ')' '->' Type ('!' EffectList)?
             | '@' 'typeof' '(' Expr ')'
             | 'type' Ident '=' Type

TypeSuffix  := '*' | '[' Expr? ']'
EffectList  := Ident (',' Ident)*

Primitives include int float double char bool byte short long void unsigned.... Pointers use *. Arrays are postfix and only postfix: int[10] a; / int[] a; (the old [10]int form is not parsed). Aliases: type CmpFn = (a: int, b: int) -> int;.

Control flow

if/else, while, do-while, for (declarations allowed in init), switch/case/default, break, continue. region r(size) { ... } opens a lexical bump scope.

Memory & regions


void* p = loi_alloc(8);
*p = 42;
int v = *p;

region r(64) {
    void* q = loi_region_alloc(r, 8);
    *q = 5;
}

Functions & effects


worker = (arg: void*): void* !IO,Alloc
{
    loi_print_str("region block");
    return arg;
}

main = () -> int !IO,Alloc
{
    region r(64) { void* v = worker(r); }
    return 0;
}

Effects after ! name capabilities (IO, Alloc, ...). A caller may only call functions whose effects are a subset of its own; assigning through a function pointer may not widen effects.

Typed function pointers


type CmpFn = (a: int, b: int) -> int;

my_less = (a: int, b: int): int { return a < b; }
cmp: CmpFn = null;              // variable holding a function pointer

main = () -> int
{
    cmp = my_less;               // assign a function as a value
    loi_print_int(cmp(2, 3));      // 1
    apply = (f: (a:int,b:int)->int, x:int, y:int): int { return f(x, y); }
    loi_print_int(apply(my_less, 2, 3));
    return 0;
}

Metaprogramming / preprocessor

Everything @ runs during a pre-lexing pass. Order of directives is preserved; branches skipped by @if never register their @define.

  • @(define NAME replacement) / @define NAME replacement
  • @(inc ...) / @(cinc ...) (see Include)
  • @if(COND) { ... } @elif(...) { ... } @else { ... }
  • @repeat(n) { body } / @for(i, A, B) { body }
  • @sizeof(T), @offsetof(T, field), @typeof(expr)
  • @section("name") { ... }, @align(n), @pack

Macros: stringify, paste, variadic


import std
@(define STR(x) @stringify(x))
@(define CONCAT(a, b) @paste(a, b))
@(define LOG(level, ...msg) { @if(level >= 1) { loi_print_str(msg); } })

int foobar = 77;

main = () -> int !IO
{
    loi_print_str(STR(hello));        // "hello"
    loi_print_str(STR(LIMIT));         // "LIMIT" (raw, not expanded)
    int foo = 1, bar = 2;
    loi_print_int(CONCAT(foo, bar));  // foobar -> 77
    LOG(1, "log: variadic works\n");
    return 0;
}

@stringify captures raw token text; @paste concatenates fragments into a token; ...msg joins the remaining args with ", ". @if inside macros is resolved in a second pass after expansion.

Packages

Programs and libraries can declare a package name:

package std

Use import pkg or import pkg.sub to load package sources. Dots are mapped to directory separators and resolution follows the same search paths (./lib, ./packages, standard system paths, LOI_PATH). @inc pkg also loads packages. See lib/ for the starter std package layout.

  • Resolution: file's directory, ./lib, ./packages, /usr/share/loi, /usr/local/share/loi, LOI_PATH. @include is no longer supported.
  • @cinc searches ., /usr/include, /usr/local/include, /usr/include/x86_64-linux-gnu.
  • Includes are guarded automatically (a file is inlined at most once per build), so libraries need no manual guards and cycles are safe. C ABIs are declared with extern ...;.

Build & run


make
./loi examples/01_basics.loi --run          # compile + run
./loi file.loi --emit=ir --out=file.ll      # emit LLVM IR
./loi file.loi --emit=asm --out=file.s      # emit assembly

Limitations

  • No C-standard-header ABI modeling; @cinc is a verifier, not importer.
  • C-style variadic functions are deferred — use variadic macros.
  • Built-in runtime calls carry no effect annotations.
