Write Loi. Run the real compiler.

The editor sends your program to a local Node server, which invokes the same loi binary used by the CLI. Nothing is simulated: the compiler checks, formats, emits C and links a native executable.

Run a program to see compiler output and program stdout. Press Ctrl+Enter to run, Shift+Ctrl+Enter to check.

Press Ctrl + Enter to run, Shift + Ctrl + Enter to check, and Tab to indent. Programs are limited to 200 KB and execute on the machine running the server, so run the server locally only. Start it with node website/server.mjs after cargo build.
